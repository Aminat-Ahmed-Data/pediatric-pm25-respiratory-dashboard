# pediatric-pm25-respiratory-dashboard

I formulated a custom dataset modeling urban pediatric PM2.5 exposure and emergency room admissions.

Ambient PM2.5 pollution spikes significantly impact respiratory health, creating severe strain on pediatric hospital admissions and emergency ventilator infrastructure in urban centers.

I engineered an automated data pipeline to ingest, clean, and analyze environmental records.

Executed MySQL table creation, deduplication, and 3-tier fallback imputation before exporting structured records into Excel to construct Pivot Table summaries and a dynamic 3x2 KPI dashboard.

The result revealed a 50% baseline ventilator occupancy rate driven by an average exposure of 53.94 µg/m³ PM2.5, providing actionable insights for health authorities.
